# payments-wallet

`Payment` + `WalletLedger` (Nigam Coins) are built (Phase 5). **Not a Mongo transaction** — the local dev mongod is standalone, not a replica set, and the user chose not to convert it rather than build around that assumption; see `../../../docs/DATA_MODEL.md` Phase 5 addendum for what this trades off. Instead: `wallet.service.js`'s `redeemCoins`/`creditCoins` are atomic at the single-document level (`findOneAndUpdate` with a balance guard), which is what actually matters for the "wallet balance consistent under concurrent requests" exit criterion (`tests/wallet.test.js`) — multi-document atomicity across payment+wallet+order is still a real, documented gap. `paymentGateway.js` is a stub; Razorpay integration assumed, confirm before building the real client. See BACKEND_CONTEXT.md §3.10.
